# ImaginaWallet 💰

ImaginaWallet was a Discord bot created in 2021 for **ImaginaCoin**,
a fictional community currency used in the Jogo Minimalista Discord server.

The bot provided simple commands for viewing accounts, balances,
currency information and other ImaginaCoin-related features.

## 🤖 Commands

- `!ajuda` — Displays available commands
- `!sobre` — Information about ImaginaWallet and ImaginaCoin
- `!cotação` — Displays the fictional currency exchange rate
- `!contas` — Lists available accounts
- `!criar` — Instructions for creating an account
- `!transferir` — Planned transfer functionality

## 🔐 Security

The Discord bot token was intentionally not included in the source code.

## 📌 Project history

ImaginaWallet was created on May 18, 2021.

Development ended on June 6, 2021, when the project was merged into
**Rogerin Poka Bala**, another Discord bot maintained by Gaspor.

The successor project can be found here:
https://github.com/Gaspor/DiscordBot
